How wrong the models still are (loss)

Loss is how surprised a model is by the real next word. Lower is better. Solid lines are measured on stories the models never train on; the faint lines are the training batches. Both models have the same number of parameters and see the same data.

How long Settle thinks per word

Each word's column keeps updating until it stops changing. These are the steps it needed, averaged over each training batch. The lens is the short two-way re-read of the last few words before predicting.

The sheet, live

Every few minutes the trainer reads a test passage word by word, exactly as the chat app does, and photographs Settle's sheet. One column per word, one row per scale: the bottom row looks one or two words back, each row above looks twice as far, and the top row spans the whole passage. Colour is the direction of each cell's state, so similar thoughts share a colour. The bars show how many steps each word took to settle. Watch it settle replays the training-time view, where all the columns settle at once.

Which words are hard, as training goes on

Each row is one photograph of the test passage (oldest at the top), and each column one word. Brighter means more thinking steps. As the model learns, you can watch it learn where to spend its effort.

Does generation match training?

The trainer settles the whole passage at once, while chat adds one word at a time. Settle is built so both give the same answer. This checks it on every photograph: the largest difference between the two in the model's scores (should stay near zero), and how often both pick the same top word (should be 100%).

What the models write

Both models continue the same prompts with the same randomness. In Settle's text, each word is tinted by how long it thought about it: brighter means more steps.
