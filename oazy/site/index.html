Small enough to run on almost nothing

The usual way to run a language model is a room full of GPUs. We are trying to go the other way: models small enough for an old laptop or the phone in your pocket, with no GPU and no connection, that still write well.

On a phone, a model writes only as fast as it can read its own weights, so we look for designs that read less for each word.
